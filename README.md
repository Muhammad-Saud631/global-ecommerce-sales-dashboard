# Global E-Commerce Sales & Performance Dashboard

An interactive Power BI dashboard developed as part of my Data Analyst Internship at Rhombix Technologies.

## Project Overview

This project focuses on analyzing e-commerce sales performance and tracking key business KPIs through interactive data visualizations.

## Key KPIs

- Total Revenue
- Total Profit
- Total Orders
- Total Customers
- Units Sold
- Average Order Value

## Dashboard Analysis

- Revenue and profit trends
- Category performance
- Product performance
- Regional analysis
- Customer segmentation
- Interactive filtering and dashboard navigation

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Analytics
- Data Visualization

## Project Preview

The dashboard consists of an overview landing page and an interactive sales performance dashboard.
